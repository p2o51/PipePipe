# PipePaw 设计主张（草稿，待 owner 确认）

PipePaw 是一个安卓原生 YouTube 客户端，Jetpack Compose + Material 3 Expressive，设计语言来自 Yoin（`~/Developer/Yoin/docs/design.md`，云端是 p2o51/Yoin），和 PiliPaw、WeiPaw 是一家。这份文档是 UI 和交互决策的依据；代码和它冲突时以它为准。

Yoin 以封面为中心，PiliPaw 以播放器为中心，WeiPaw 以「一行一行往下读」为中心，**PipePaw 以「边看边逛」为中心**：画面一直在，页面在它下面换。规则继承 Yoin，形态从这个动作出发。两句总纲：「神似，不能一样」；「做不到更轻盈的就别做了」。

## 0. 已定

- 上游 PipePipe（InfinityLoop1308，GPL-3.0）。**只链接它的 Extractor**（子模块，composite build）；PipePipeClient 是只读参考，只拿接口用法和功能清单，UI、交互、动效一点不参考它。（讨论稿 A 路线，owner 2026-10-21「可以开始实现了」）
- 名字暂定 PipePaw，包名 `com.gpo.pipepaw`（取上游客户端名，和 PiliPaw 同一规则；待 owner 在卡片上确认）。
- 播放器是**壳里的覆盖层**，不是页面（讨论稿问题 2 的推荐）：Yoin Now Playing 的 ShellOverlayDown，迷你条 ⇄ 全屏是同一条进度。
- 不登录也完整：订阅、历史、稍后再看全在本机。登录（mweb + SABR）是后面的可选项。
- Paw 套件先从 PiliPaw 拷（主题、seam、页面转场、FameCount、设置套件），不抽库（讨论稿问题 4 暂按「速度优先」）。图标例外：2026-10-29 起和 Yoin、其他 Paw 一样直接用 yoin-symbols 库（`includeBuild ../yoin-symbols`），不再拷贝。

## 1. 形态：画面一直在

- 全屏播放器：画面贴顶（状态栏下），16:9，宽度占满；控件**全部在画面下方**，用页面配色（PiliPaw 0.3.3）。画面上不放任何东西，暂停也不盖图标。
- 迷你条：64dp 高，左边是同一个画面，右边标题、频道、播放、关闭。浮在底栏上方（壳里）或页面底部（推入页），宽度封顶 560dp 居中，和底栏同一条中线。
- 展开 / 收起：容器矩形和画面矩形同时插值，**画面是同一个 TextureView 一路飞**，不换图、不黑帧。拖动跟手，松手交给空间弹簧，速度够就按方向走。
- 返回：全屏时系统返回、下滑、收起按钮共用一个进度。预测性返回手势预览 30% 的收起，松手才落定；取消弹回。迷你时不拦返回。
- **全屏（横屏铺满）**：画面占满窗口，平时什么都不显示。点一下，控件出来，**画面让位而不是被盖住**：画面保持比例缩小成圆角卡片（20dp），退到顶栏（返回、标题）和底栏（播放、时间、进度条、退出全屏）之间的带子里；再点一下，卡片弹回铺满。播放时 3 秒无操作自动收起。全程同一个空间弹簧（Expressive），画面上不叠任何控件，这是「控件在画面下方」在全屏里的样子（PiliPaw 的做法，owner 2026-10-21 定）。
  - 窗口：隐藏系统栏；手机横放横屏视频转横屏；大屏先请求旋转，平台只给信箱（Pixel Tablet）时画面自己转 90°，跟着重力换方向。
  - 返回键退出全屏，回到展开的播放器。
- 从卡片点开（下一步）：缩略图作为共享元素飞成画面，和 PiliPaw「视频帧飞回卡片」对称。

## 2. 节奏

| 角色 | 字阶 | 说明 |
| --- | --- | --- |
| 卡片标题 | titleMedium | 两行 |
| 频道、播放量、时间 | labelMedium | onSurfaceVariant，分开的 Text，不用「·」拼 |
| 播放页标题 | titleLarge | 三行 |
| 计数 | 值 labelLarge w600 + 标签 | 「12万」「次观看」两段；名声模式下变成短线 |

- 卡片：手机单列大卡（缩略图到边、下方头像 + 标题 + 一行元数据），12dp 连续圆角封面，无描边。
- 时长坐在缩略图右下的小色块里（唯一允许压在图上的东西，图片上的 scrim 是唯一的硬编码颜色）。

## 3. 克制和放开

克制：滚动时零动效（只有 seam 溶解）；列表不错落入场；数字静态；背景晕染是静止的。

放开：用户亲手做的那一下——展开 / 收起播放器、订阅（按钮形变 + 触感）、点赞、拖动进度。

系统关掉动画：弹簧换原地淡入淡出。

## 4. Hero moment

**A 画面飞行**：迷你条 ⇄ 全屏一条运动，画面在两个位置之间连续飞，返回手势跟手预览。（骨架已有）

**B 段落进度条**（已做）：章节、SponsorBlock 片段、「最常重播」热度（接口有的话）同一条进度条上的同一套语言：章节是缝，赞助片段是另一种色块；跳过时那一段在进度条上「合拢」，同时底部一行「已跳过赞助」带「撤销」（owner 2026-10-21 同意）。

**C 听 YouTube**（待做）：仅听声音时画面收成封面，进入 Yoin 式 Now Playing：封面取色、字幕当歌词滚动。

## 7. 大屏（第一天就做）

每页先定 Compact / Medium / Expanded 的形态，只看自己的容器，先判高再判宽；画面永不变小；在 Pixel Tablet 竖横屏实测。

| 页面 | Compact < 600 | Medium 600–840 | Expanded ≥ 840（且高 ≥ 480） |
| --- | --- | --- | --- |
| 首页 / 频道 | 单列大卡 | 两列 | 三列起（卡片最小 320dp） |
| 播放器 | 画面在上，详情和相关视频在下 | 同左，画面封顶 62% 高 | 左：画面 + 控件 + 详情；右：400dp 相关视频列 |
| 迷你条 | 左右各 12dp | 封顶 560dp 居中 | 同左 |
| 搜索 / 订阅 / 设置 | 列表 | 阅读宽度 | 阅读宽度 |

横屏手机（高 < 480）：不分栏，画面按高度封顶，详情在下面滚。
